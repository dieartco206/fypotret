# FYPotret — Jasa Fotografi Modern & Responsive

Website resmi dan portofolio interaktif untuk **FYPotret** ([@fypotretid](https://instagram.com/fypotretid)).

> *"Capturing Love, Joy, & Memories ✨"*  
> Spesialis dokumentasi Wedding, Prewedding, Wisuda (Graduation), Birthday & Kids, dan Turnamen / Event Dokumentasi di Tangerang, Depok, dan Jakarta.

---

## 🎨 Desain & UI/UX Standards

Website ini dibangun dengan filosofi **Anti-AI-Slop & Mobile-First**:
- **Palet Warna Luxury Editorial:** Deep Obsidian Black (`#070709`, `#0B0C0E`) dengan aksen Warm Amber Gold (`#F59E0B`, `#D4AF37`) yang senada dengan logo kamera FYPotret.
- **Tipografi Berkelas:** Google Fonts *Playfair Display* (Editorial Headline) dan *Plus Jakarta Sans* (Clean Body & UI).
- **Mobile Ergonomics (HP First):**
  - Seluruh tombol dan area sentuh memiliki minimal ukuran **44px x 44px** (Apple HIG & Material Design 3).
  - Floating WhatsApp Booking Button di area jangkauan jempol (*Thumb-Zone*).
  - Story Highlight bergaya Instagram dengan carousel horizontal ramah sentuhan.
- **Fitur Galeri Interaktif:**
  - Dynamic Bento Grid Gallery dengan filter kategori instan.
  - Fullscreen Lightbox Viewer (Swipe, zoom, dan keyboard navigation).
  - Direct WhatsApp Booking Engine dengan template pesan otomatis.

---

## 🚀 Tech Stack

- **Framework:** React 19 / Vite 6 (TypeScript)
- **Styling:** Tailwind CSS + PostCSS + Custom Obsidian & Gold Themes
- **Icons:** Lucide React + Custom SVG Brand Icons
- **Animation:** CSS Keyframes & Framer Motion Ready
- **Linting & Code Quality:** TypeScript strict mode, Oxlint

## 🛠️ Menjalankan Proyek Lokal

```bash
# Clone repository
git clone https://github.com/dieartco206/fypotret.git
cd fypotret

# Install dependensi
npm install

# Jalankan development server
npm run dev

# Build untuk produksi
npm run build

# Preview build produksi
npm run preview
```
